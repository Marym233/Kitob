# Kitob

A practice online shop for K-beauty, J-beauty and C-beauty skincare and makeup. I'm building it to learn how a full website and a mobile app are put together.

## Who it's for

It's for customers who want to buy K-beauty (Korean), J-beauty (Japanese) and C-beauty (Chinese) makeup and skincare.

## What it will do

- Show a list of products
- Show a description for each product
- Show whether a product is vegan
- Show whether a product is cruelty-free

Vegan and cruelty-free are shown as separate labels because they mean different things. Vegan is about a product's ingredients. Cruelty-free is about whether it was tested on animals.

## How the repo is organised

Kitob uses one repo for the website and the mobile app. I chose this because I'm working alone, both parts will use the same database, and I can keep all my tickets and my project board in one place.
